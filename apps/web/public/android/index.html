แอป BigB POS

สำหรับแท็บเล็ต Android · พิมพ์ใบเสร็จทางบลูทูธ

⬇ ดาวน์โหลดแอป

เวอร์ชัน 1.2 · 61 KB · Android 7 ขึ้นไป

1. จับคู่เครื่องพิมพ์ (ทำครั้งเดียว)

ตั้งค่า → บลูทูธ → เปิดเครื่องพิมพ์ → แตะชื่อเครื่องพิมพ์ (เช่น Printer001) ให้ขึ้นใน "อุปกรณ์ที่จับคู่"

2. ติดตั้ง

  1. กดปุ่ม ดาวน์โหลดแอป ด้านบน
  2. เมื่อโหลดเสร็จ แตะไฟล์ BigB-POS.apk เพื่อติดตั้ง
  3. ถ้าขึ้นว่าไม่อนุญาตให้ติดตั้งจากแหล่งที่ไม่รู้จัก กด ตั้งค่า → เปิดอนุญาตให้เบราว์เซอร์นี้ → กลับมากดติดตั้งอีกครั้ง
  4. ถ้าแท็บเล็ตเตือนเรื่องความปลอดภัย เลือก ติดตั้งต่อ

3. เริ่มใช้

  1. เปิดแอป BigB POS จากหน้าจอหลัก แล้วเข้าสู่ระบบด้วย PIN
  2. กดไอคอนเครื่องพิมพ์ที่แถบบน → เลือกขนาดกระดาษ → พิมพ์ทดสอบ
  3. อนุญาตบลูทูธ แล้วเลือกเครื่องพิมพ์ — ใบทดสอบออกแล้วพร้อมขาย

เปลี่ยนเครื่องพิมพ์: กด "พิมพ์ทดสอบ" อีกครั้ง แอปจะให้เลือกใหม่

อัปเดตแอป: เปิดหน้านี้แล้วดาวน์โหลดติดตั้งทับได้เลย ข้อมูลในแอปยังอยู่ · กลับหน้า POS
