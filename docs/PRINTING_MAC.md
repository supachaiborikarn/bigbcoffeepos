# พิมพ์ใบเสร็จอัตโนมัติบน Mac (เครื่องพิมพ์ความร้อน 58 มม.)

POS สั่งพิมพ์ใบเสร็จทันทีหลังกดเก็บเงินอยู่แล้ว แต่เบราว์เซอร์ปกติ (Chrome, Safari, Comet)
บังคับให้ขึ้นหน้าต่างพิมพ์ให้กดยืนยันทุกครั้ง เว็บไม่สามารถข้ามขั้นนี้เองได้
วิธีที่ทำให้พิมพ์ออกเองคือเปิด Chrome ด้วยโหมด `--kiosk-printing` ผ่านไฟล์
[`native/mac-kiosk/BigB-POS.command`](../native/mac-kiosk/BigB-POS.command)

## ตั้งค่าครั้งเดียวบน Mac ที่หน้าร้าน

1. ติดตั้งไดรเวอร์เครื่องพิมพ์ความร้อน แล้วเพิ่มเครื่องใน
   System Settings → Printers & Scanners
2. ตั้ง **Default printer** เป็นเครื่องพิมพ์ความร้อน
   (โหมดอัตโนมัติจะพิมพ์ไปเครื่อง Default เสมอ ไม่มีหน้าต่างให้เลือกเครื่อง)
3. ในตัวเลือกของเครื่องพิมพ์ ตั้งขนาดกระดาษเริ่มต้นเป็น 58 มม. (เช่น 58 x 210mm / Roll paper 58mm)
4. คัดลอก `BigB-POS.command` ไปไว้ที่ Desktop แล้วดับเบิลคลิก
   (ครั้งแรกถ้า macOS เตือน ให้คลิกขวา → Open)
5. ล็อกอิน POS ในหน้าต่างที่เปิดขึ้น (โปรไฟล์แยก ล็อกอินครั้งเดียว)
6. ไปที่ ตั้งค่าเครื่องพิมพ์ ใน POS → วิธีพิมพ์ "พิมพ์ผ่านเบราว์เซอร์" และ ขนาดกระดาษ "58 มม."
   แล้วกด "พิมพ์ทดสอบ" ต้องออกกระดาษทันทีโดยไม่มีหน้าต่างถาม

## หมายเหตุ

- ใช้ได้กับ Google Chrome เท่านั้น (ไม่รองรับ Safari; Comet ไม่ได้ทดสอบ)
- ต้องเปิด POS จากไฟล์นี้ทุกครั้ง ถ้าเปิดจาก Chrome/Comet ปกติจะกลับไปขึ้นหน้าต่างพิมพ์ตามเดิม
- ทุกอย่างที่สั่งพิมพ์ในหน้าต่างนี้จะออกทันที รวมถึงใบสรุปส่งยอดจากหน้ารายงาน
- เปลี่ยน URL ได้ด้วยตัวแปร `BBPOS_URL` เช่นสำหรับทดสอบ
