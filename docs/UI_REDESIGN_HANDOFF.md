# สถานะงาน UI และสิทธิ์สาขา benzPOS

ปรับปรุง 7 กันยายน 2026

ผู้ใช้สั่งให้ผู้ช่วยเดิมลงมือพัฒนาแล้ว และให้เพิ่มบ่อถ่ายน้ำมันพงษ์อนันต์ได้ ไม่มีการส่งงานให้ AI อื่น

## เริ่มอ่านจากที่นี่

- [บันทึกการพัฒนาและผลทดสอบ](UI_REDESIGN_IMPLEMENTATION.md) เป็นสถานะล่าสุด
- [แผนทั้งระบบ](UI_REDESIGN_PLAN.md) มีเป้าหมายที่ลงโค้ดแล้วและเป้าหมายระยะถัดไป
- `AGENTS.md` เป็นกฎของ repository
- `docs/ui-redesign/prototype-preview.html` เป็นตัวอย่างทิศทางเดิมที่ใช้ข้อมูลจำลอง

## ลงโค้ดแล้ว

- หน้าเข้าสู่ระบบ โครงเมนู หน้าขายกาแฟและบ่อถ่ายน้ำมัน สต็อกผู้จัดการ และสมาชิก ใช้สี/ส่วนประกอบชุดใหม่ รองรับหน้าจอเล็กและโหมดมืด
- พนักงานและผู้จัดการเห็นสาขาประจำจากข้อมูลเดิม ส่วน admin คงสิทธิ์ส่วนกลางตามระบบเดิม
- ฝั่งเซิร์ฟเวอร์โหลดสิทธิ์ล่าสุดก่อนรับคำขอ และตรวจสาขาของรายการก่อนอ่านหรือแก้ไข
- แยกตะกร้า บิลพัก สมาชิก กะ และคิวออฟไลน์ตามผู้ใช้กับสาขา
- รับเงินสด QR บัตร และ Wallet ตามช่องทางที่สาขาเปิดไว้ โดยช่องทางที่ไม่ใช่เงินสดยังใช้พนักงานยืนยัน
- บ่อถ่ายน้ำมันบันทึกทะเบียน เลขไมล์ และรายละเอียดงานในหมายเหตุบิลได้ ยังไม่มีฐานประวัติรถหรือระบบใบงานแยก
- สมาชิกเดิมที่สาขาไม่ชัดเจนมีรายชื่อให้ admin ตรวจและผูกสาขาเอง โดยไม่มีการย้ายอัตโนมัติ

## ข้อมูลสาขาจริง

| รหัส | สาขา | พนักงานเดิม |
| --- | --- | --- |
| 1 | กาแฟ วัชรเกียรติ | จ๋า |
| 2 | กาแฟ พงษ์อนันต์ | กวาง, กฐิน |
| 3 | กาแฟ ศุภชัย | นก |
| 4 | บ่อถ่ายน้ำมัน วัชรเกียรติ | หมู, เผือก, เบิ้ม |
| 132 | บ่อถ่ายน้ำมัน พงษ์อนันต์ | ยังไม่มีผู้ผูกสาขา |

สร้างสาขา 132 ในฐานที่แอปใช้อยู่แล้วด้วยสคริปต์เพิ่มเฉพาะสาขา และตรวจซ้ำว่าไม่สร้างรายการซ้ำ โดยไม่แก้การมอบหมายพนักงานเดิม

บัญชี “ผู้จัดการ” เป็น admin ที่ไม่มี branchId และคงการเลือกทุกสาขา ส่วนแคชเชียร์ 1 และ 2 ยังไม่มีสาขาจึงเข้าใช้งานขายไม่ได้จนกว่าจะผูกสาขา

## งานที่ยังเหลือจากแผนใหญ่

- กำหนดพนักงาน สต็อกเริ่มต้น บัญชีรับเงิน และเครื่องพิมพ์ของสาขา 132 จากข้อมูลร้านที่ยืนยันแล้ว
- แบ่งชำระ เชื่อมผู้ให้บริการรับเงิน การคืนเงินผ่านผู้ให้บริการ และระบบใบงาน/ประวัติรถ ยังไม่ได้ทำ
- เมนู สูตร และโปรโมชั่นยังเป็นข้อมูลส่วนกลาง โดยเมนูแยกตามประเภทร้านและอนุญาตให้ admin แก้ไข หากต้องมีราคาและโปรโมชั่นแยกแต่ละสาขาต้องทำโครงข้อมูลเพิ่ม
- หน้ารายงาน ออเดอร์ คิว และงานดูแลส่วนกลางได้รับโครงหน้าและธีมร่วม แต่ยังไม่ได้เปลี่ยนรายละเอียดทุกหน้าตามแผนใหญ่

## ข้อควรระวังในการทำต่อ

มีไฟล์แก้ค้างจากงานอื่น โดยเฉพาะการเชื่อม POSPOS, MigrationPage, SettingsPage, package files และ iOS wrapper ให้ตรวจ diff ก่อนแก้และอย่า reset หรือ commit รวมโดยไม่แยกขอบเขต

ไม่ต้องรัน seed หรือ migration กับข้อมูลร้านจริงเพื่อทดสอบ ชุดขายและสิทธิ์ทดสอบบนฐานแยกหรือข้อมูลจำลองแล้ว ดูคำสั่งในบันทึกการพัฒนา

รุ่น UI/API นี้เผยแพร่ตามคำสั่งผู้ใช้แล้วที่ https://bigbcoffeepos-web.vercel.app เมื่อ 7 กันยายน 2026 โดยแยกงาน POSPOS ที่ค้างอยู่ออกจากชุดเผยแพร่และยังไม่ได้ commit รวมไฟล์เหล่านั้น การเปลี่ยนข้อมูลจริงมีเพียงการเพิ่มสาขา 132 ไม่มีการสร้างบิลทดสอบจริง ผลตรวจคำขออ่านและสิทธิ์ 13 กรณีผ่านทั้งก่อนและหลังสลับโดเมน
