# BigB POS — แอป Android (พิมพ์ใบเสร็จทางบลูทูธ)

แอปนี้เปิดเว็บ POS (`https://bigbcoffeepos-web.vercel.app/pos`) แบบเต็มจอ และพิมพ์ใบเสร็จ
เข้าเครื่องพิมพ์ความร้อนที่จับคู่บลูทูธไว้ (เช่น Xprinter ที่ชื่อ **Printer001**) ได้โดยตรง

ทำมาเพื่อแท็บเล็ตบ่อถ่ายน้ำมัน (HUAWEI MatePad T8) ซึ่ง:
- ไม่มี Google Play จึงลงแอป RawBT ไม่ได้
- ใช้ Huawei Browser ซึ่งสั่งเครื่องพิมพ์บลูทูธจากหน้าเว็บไม่ได้

วิธีพิมพ์: เว็บส่งใบเสร็จ (HTML) มาให้แอป แอปวาดใบเสร็จเป็นรูปแล้วส่งเป็นภาพไปเครื่องพิมพ์
ภาษาไทย สระบน/ล่าง และวรรณยุกต์จึงออกเหมือนบนจอทุกตัว ไม่พึ่งฟอนต์ในเครื่องพิมพ์
(ใช้ช่องทางเดียวกับแอป iPad ที่ `native/ios-wrapper` — โค้ดฝั่งเว็บอยู่ที่ `apps/web/src/utils/nativePrinter.ts`)

## ติดตั้งบนแท็บเล็ต

### 1. จับคู่เครื่องพิมพ์ (ทำครั้งเดียว)
ตั้งค่า → บลูทูธ → เปิดเครื่องพิมพ์ → แตะ **Printer001** ให้ขึ้นใน "อุปกรณ์ที่จับคู่"
(ถ้าถามรหัส ลอง `0000` หรือ `1234`)

### 2. ลงแอป
1. ส่งไฟล์ `BigB-POS-1.0.apk` ไปที่แท็บเล็ต (ทาง LINE, Google Drive หรือสาย USB ก็ได้)
2. แตะไฟล์ .apk เพื่อติดตั้ง
3. ถ้าเครื่องเตือนว่าไม่อนุญาตให้ติดตั้งจากแหล่งที่ไม่รู้จัก ให้กด **ตั้งค่า** แล้วเปิด
   "อนุญาตการติดตั้งแอป" ให้แอปที่ใช้เปิดไฟล์ (เช่น LINE หรือ ไฟล์) แล้วกลับมากดติดตั้งอีกครั้ง
4. ถ้า Huawei ขึ้นคำเตือนความปลอดภัย ให้เลือก "ติดตั้งต่อ"

### 3. ใช้งาน
1. เปิดแอป **BigB POS** จากหน้าจอหลัก (เปิดเต็มจอเอง ปัดขอบบน/ล่างเพื่อเรียกแถบระบบ)
2. เข้าสู่ระบบด้วย PIN และเลือกสาขา **บ่อถ่ายน้ำมัน วัชรเกียรติ** ตามปกติ
3. ตั้งค่าเครื่องพิมพ์ (ไอคอนเครื่องพิมพ์ที่แถบบน) → ขนาดกระดาษ **58 มม.** → กด **พิมพ์ทดสอบ**
4. ครั้งแรกแอปจะขออนุญาต "อุปกรณ์ใกล้เคียง/บลูทูธ" ให้กดอนุญาต แล้วเลือก **Printer001**
5. ใบทดสอบออก = พร้อมขาย หลังจากนี้ใบเสร็จจะพิมพ์ไปเครื่องนี้เอง

**เปลี่ยนเครื่องพิมพ์:** กด "พิมพ์ทดสอบ" อีกครั้ง แอปจะให้เลือกเครื่องพิมพ์ใหม่ทุกครั้งที่พิมพ์ทดสอบ

### ถ้ามีปัญหา
| อาการ | ทางแก้ |
|---|---|
| "เชื่อมต่อเครื่องพิมพ์ไม่ได้" | เปิดเครื่องพิมพ์ ให้อยู่ใกล้แท็บเล็ต และตรวจว่าไม่มีแท็บเล็ต/มือถือเครื่องอื่นต่อเครื่องพิมพ์ค้างอยู่ |
| "บลูทูธปิดอยู่" | เปิดบลูทูธแล้วพิมพ์ใหม่ |
| หน้าจอเพี้ยน ปุ่มซ้อนกัน | อัปเดต "Android System WebView" หรือ "Huawei WebView" ใน AppGallery |
| เปิดแอปแล้วขึ้น "เชื่อมต่ออินเทอร์เน็ตไม่ได้" | ตรวจ Wi-Fi แล้วกด "ลองใหม่" |

## สร้างแอปใหม่ (สำหรับคนดูแลระบบ)

ต้องมี JDK 17 และ Android SDK (platform 35, build-tools 35)

```bash
cd native/android-wrapper
cp ~/Documents/BigB-POS-android-key/keystore.properties .   # กุญแจเซ็นแอป (ดูด้านล่าง)
echo "sdk.dir=/opt/homebrew/share/android-commandlinetools" > local.properties
JAVA_HOME=/opt/homebrew/opt/openjdk@17 ./gradlew assembleRelease
# ได้ไฟล์ app/build/outputs/apk/release/app-release.apk
```

- ทุกเวอร์ชันใหม่ ให้เพิ่ม `versionCode` (และ `versionName`) ใน `app/build.gradle` แล้วลงทับของเดิมได้เลย
- **กุญแจเซ็นแอปอยู่ที่ `~/Documents/BigB-POS-android-key/`** (ไม่อยู่ใน git) ต้องใช้กุญแจเดิมทุกครั้ง
  ถ้ากุญแจหาย แท็บเล็ตจะไม่ยอมลงทับ ต้องลบแอปเก่าก่อน ควรสำรองโฟลเดอร์นี้ไว้
- ที่อยู่เว็บ POS ตั้งไว้ที่ `MainActivity.POS_URL` แอปเปิดได้เฉพาะเว็บนี้ ลิงก์เว็บอื่นจะเปิดนอกแอป
  และเฉพาะหน้าของเว็บนี้เท่านั้นที่สั่งพิมพ์ผ่านแอปได้

### โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `MainActivity.java` | WebView เต็มจอ, เปิดจอค้าง, เลือกเครื่องพิมพ์, ขอสิทธิ์บลูทูธ |
| `PrintBridge.java` | `window.BBPOSNative` ที่เว็บเรียก (`printReceipt`) และส่งผลกลับเป็น event `bbpos-native-print-result` |
| `ReceiptRenderer.java` | วาดใบเสร็จ HTML เป็นรูปกว้างเท่าหัวพิมพ์ (58 มม. = 384 จุด, 80 มม. = 576 จุด) |
| `EscPos.java` | แปลงรูปเป็นคำสั่ง ESC/POS (`GS v 0`) + ตัดกระดาษ — เป็น Java ล้วน ทดสอบบนคอมได้ |
| `BluetoothPrinter.java` | ต่อเครื่องพิมพ์ทาง Bluetooth SPP แล้วส่งข้อมูล |
