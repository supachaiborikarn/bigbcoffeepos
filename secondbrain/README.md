# benzPOS Second Brain

This folder is an Obsidian vault for the benzPOS / Wazabin POS project.

## How to use

1. Open Obsidian.
2. Choose `Open folder as vault`.
3. Select this folder: `secondbrain`.
4. Start from [[00-Start-Here]].

## Structure

- `00-Start-Here.md`: launch point for future sessions.
- `notes/`: project map, architecture, API notes, runbook, decisions, backlog, session log.
- `templates/`: reusable Obsidian note templates.
- `inbox/`: drop quick notes here before organizing.
- `_attachments/`: images, PDFs, and other vault attachments.

Keep notes short, linked, and dated. When code behavior changes, update the related note in the same commit or session.
